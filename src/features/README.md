# features/

One folder per feature. Each holds the components and hooks that belong only to it.

- `posts/`: PostList, PostCard, FilterBar, Pager (previous/next)
- `comments/`: CommentList, CommentItem, CommentForm
- `authors/`: AuthorCard, AuthorStats
- `bookmarks/`: BookmarkButton, BookmarkList
- `recently-viewed/`: RecentlyViewedStrip

Keep each feature's tests next to its files (`PostCard.test.jsx`).
